# Problem Cases — IMS2050

This directory is the canonical registry for problem cases entering the IMS2050 problem-discovery workflow.

## Rule

Each accepted problem candidate receives an independent case directory. The case is continued and validated on its own evidence track.

## Current Cases

- `DISNEY-001/` — Disney Experiences / Capacity Creation
- `UK-MOJ-001/` — UK Ministry of Justice / CJS Digital Transformation / Information Friction
- `WATER-001/` — Water / customer-side supply-pipe leakage friction
- `INDIA-AI-001/` — IndiaAI Innovation Challenge 2026

## Separation of concerns

- METHOD-CORE defines the problem-solving methodology.
- Problem Cases contain problem-specific evidence, validation, economics, ownership, and intervention records.
- No problem case is considered validated merely because it entered this registry.
